# MuxRay v0.1.0

MuxRay 首个公开版本，面向音视频开发者提供本地 FLV 结构与码流分析。
从媒体概览、时间戳和 Tag 趋势出发，逐步定位到编解码器字段与原始字节。

## 本版亮点

- **FLV 结构检查**：Tag 索引、结构诊断、类型/DTS 筛选与精确定位。
- **编解码器详情**：AMF0、AAC、AVC/H.264 和 MP3，支持 NAL、slice、SEI 及 MP3 帧信息查看。
- **趋势与检索**：媒体码率、声明 GOP、时间戳变化，以及 H.264、MP3、SEI 的批量检索。
- **Hex 联动与导出**：从字段和诊断跳转原始字节，保存当前分析结果为 JSON。

## 下载与运行

| 文件 | 用途 |
| --- | --- |
| [MuxRay-v0.1.0-windows-x64.zip](https://github.com/sevico/MuxRay/releases/download/v0.1.0/MuxRay-v0.1.0-windows-x64.zip) | Windows x64 桌面便携版 |
| [SHA256SUMS.txt](https://github.com/sevico/MuxRay/releases/download/v0.1.0/SHA256SUMS.txt) | 下载文件的 SHA-256 校验值 |
| [BUILD-INFO.json](https://github.com/sevico/MuxRay/releases/download/v0.1.0/BUILD-INFO.json) | 构建版本、源码提交与程序摘要 |

运行前需安装 **Microsoft Edge WebView2 Runtime**。完整解压 ZIP 后运行 `MuxRay.exe`，
点击“打开 FLV 文件”开始分析。便携包包含桌面程序；CLI 可按
[命令行指南](https://github.com/sevico/MuxRay/blob/main/docs/cli-guide.md)从源码构建。

可在 PowerShell 中核验 ZIP，结果应与 `SHA256SUMS.txt` 对应条目一致：

```powershell
Get-FileHash -LiteralPath 'MuxRay-v0.1.0-windows-x64.zip' -Algorithm SHA256
```

## 使用说明

本版只读分析单个本地 FLV，不提供播放、修复、转码或实时流接入。
扫描与检索按范围处理，请结合完整性提示阅读结果。JSON 保存当前已加载内容，
不包含时间戳检索页；导出可能含元数据和有限原始字节，分享前请检查。

Windows 版本仍有异常退出及重复打开文件框时资源占用增长的已知问题。
平台、分析范围及使用注意事项见
[支持范围](https://github.com/sevico/MuxRay/blob/main/docs/preview-scope.md)，
操作步骤见[使用指南](https://github.com/sevico/MuxRay/blob/main/docs/preview-guide.md)。
