# MuxRay v0.2.0

这一版可以把时间戳检索结果连同趋势、详情和原始字节保存到诊断快照，方便复核 FLV 文件中的时间戳观察。

## 本次更新

- 完成时间戳检索后，诊断快照 JSON v5 保存当前批次、筛选与阈值、连续已检范围，以及命中 Tag 和已知前驱。
- 保留快照 v1–v4 的格式。没有当前已完成的时间戳检索页时，仍按已加载的内容选用对应的早期格式。
- 提供从时间戳检索到详情、Hex 和保存的[操作示例](https://github.com/sevico/MuxRay/blob/v0.2.0/docs/quick-start-example.md)。
- 桌面包使用 Go 1.27.4 构建，纳入该版本的标准库安全修复。

## 下载与运行

在 [GitHub Releases](https://github.com/sevico/MuxRay/releases) 获取 `MuxRay-v0.2.0-windows-x64.zip`。
发行页提供 `SHA256SUMS.txt` 和 `BUILD-INFO.json`，用于核对下载文件与源码提交。

Windows x64 需预先安装 Microsoft Edge WebView2 Runtime。完整解压后运行 `MuxRay.exe`。
便携包包含桌面程序、构建信息、MIT 许可证及第三方许可通知。
CLI 可按[命令行指南](https://github.com/sevico/MuxRay/blob/v0.2.0/docs/cli-guide.md)从源码构建。

## 使用范围

MuxRay 只读检查单个本地 FLV，快照保存当前已加载的结果，包含当前相关检索页。
时间戳观察需要结合扫描完整性和实际检查范围理解。分享快照前，请检查其中的元数据和原始字节。

Windows 曾出现异常退出，长时间反复打开系统文件对话框也可能增加进程资源占用。
请参阅[使用说明与已知问题](https://github.com/sevico/MuxRay/blob/v0.2.0/docs/preview-scope.md)，
或通过 [Issues](https://github.com/sevico/MuxRay/issues) 提交版本、环境和复现步骤。
