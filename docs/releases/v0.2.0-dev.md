# MuxRay v0.2.0-dev

这是开发候选版本，用于验证下一版桌面功能与打包流程，尚未公开发行。
当前公开版本仍为 [v0.1.0](https://github.com/sevico/MuxRay/releases/tag/v0.1.0)。

## 本次更新

- 时间戳检索结果可随诊断 JSON v5 保存：包括当前已完成批次、实际筛选与阈值、
  连续已检范围、当前 Tag 及已知前驱；可与趋势、详情和 Hex 一起复核。
- 保留已有 v1–v4 快照合同。导出只保存已加载结果，不补做扫描或收集历史全部批次。
- 新增可生成样本的操作示例及问题、使用体验反馈模板。
- 候选包工具核对源码提交、实际程序、第三方许可证与校验和，并重新解包验证。

## 运行与范围

Windows x64 便携包需要预先安装 Microsoft Edge WebView2 Runtime，完整解压后运行
`MuxRay.exe`。包内含构建信息、MIT 许可证及第三方通知；不含 CLI、安装器或媒体样本。

MuxRay 只读检查本地 FLV，不提供播放、修复或转码。时间戳回退、重复与大间隔是
容器观察，不直接证明播放异常。诊断 JSON 可能含元数据文本和有限媒体字节，分享前请检查。

Windows 历史异常退出及重复打开文件选择框的资源占用仍按
[支持范围](https://github.com/sevico/MuxRay/blob/main/docs/preview-scope.md#已知问题)记录。候选包生成成功只证明构建和打包核验完成；
原生操作、退出及持续集成结果须分别核验，不由打包工具推定。
