## 原生流程与独立核对

样本由 `tools/desktop-native/time_search_fixtures.py` 生成，用于封装/时间戳验证，
不代表可播放音频。实际窗口标题与导出 `producer.version` 均为 `0.2.0-dev`。

1. 原生选择样本，扫描得到 10,000 个 Tag，容器索引完整。
2. 保持 DTS 回退、阈值 1000 ms，依次检查 `[0,4096)`、`[4096,8192)`、`[8192,10000)`。
   前两批无命中，第三批检查 1808 个 Tag、命中 1 条；连续已检范围为 `[0,10000)`。
3. Tag 8192 的 DTS 为 163720 ms，前驱 Tag 8191 的 DTS 为 163820 ms，差值 −100 ms。
   点击观察项后，趋势窗口为 `[8192,8448)`，AAC 详情保持同一个 Tag。
4. 点击 AAC 字段源位置，Hex 窗口为 `[155672,156184)`，512 byte，开头为 `af 01 aa bb`。
5. 原生保存为新 JSON 文件，界面报告 73,108 byte。独立 `snapshot_check.py --source`
   通过 v5 Schema，并从源文件核对全部 256 个趋势点、512 字节 Hex、时间戳命中及前驱。
   当前页条件、连续范围与请求身份一致，未导出时间戳续查游标。
6. 关闭文件后恢复空状态；程序仍存活时，源文件独占只读打开成功，SHA-256 未变化。
7. 正常关闭窗口，外部 `capture_exit.py` 记录退出码 **0**；stdout/stderr 均到达 EOF、
   未截断且持久化摘要一致，无观察超时、采集器中断或遗留目标窗口。
