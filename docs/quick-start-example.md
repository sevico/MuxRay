# 示例：找到时间戳回退并保存分析结果

这个示例演示“打开文件 → 找到观察项 → 查看字段与 Hex → 保存 JSON”。
可以使用自己的 FLV 文件；如需复现下文的精确数值，开发者可在仓库根目录运行：

```powershell
python tools/desktop-native/time_search_fixtures.py --output-dir C:\MuxRaySamples\time-search-demo
```

输出目录必须是尚不存在的绝对路径。生成的 `time-search-long.flv` 包含 10,000 个 Tag，
用于观察封装时间戳和 AAC 包头，不是可播放的音频样本。

## 1. 打开文件

运行 MuxRay，点击“打开 FLV 文件”，选择样本。扫描结束后核对 Tag 数和完整性。
在这个样本中，应看到 **10,000 个 Tag、容器索引完整**。

## 2. 查找并定位

进入“时间戳观察检索”，保留“DTS 回退”，点击“从头检索时间戳”。
前两批没有命中，分别检查 `[0, 4096)` 和 `[4096, 8192)`；点击继续后，
第三批 `[8192, 10000)` 找到 **Tag 8192**：

| 字段 | 结果 |
| --- | --- |
| 前驱 Tag | 8191 |
| 前驱 DTS | 163820 ms |
| 当前 DTS | 163720 ms |
| 差值 | −100 ms |

点击命中项的“趋势与详情”，查看所在趋势窗口与 AAC 字段。点击字段的源位置，
在 Hex 中核对字节；该 Tag 的 payload 从 byte 155672 开始，前四字节为 `af 01 aa bb`。
这说明容器中存在回退观察，不据此判定播放质量。

## 3. 保存与反馈

等相关详情和 Hex 加载完成，点击“返回页首导出”，再选择“导出诊断 JSON”。

- **开发分支的快照 v5**：有当前已完成的时间戳检索页时，保存该页的条件、阈值、
  命中项和连续已检范围，以及已加载的趋势、详情和 Hex。
- **已发行 v0.1.0**：保存 v3/v4，不包含时间戳检索页；请另外记录条件与检查范围。

快照保留当前页，不汇总所有历史命中，也不能恢复原会话的续查状态。
保存后可关闭文件。分享前检查 JSON 中的元数据文本与原始字节。
