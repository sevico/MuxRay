# Linux 扩展验收：有效媒体、容量边界与生命周期

接续 [Linux 构建与首轮验证](desktop-linux-20261007.md)。Linux 支持已在本地提交为
`08d62e66defa174a74ac4cab3bff24072f2a1a2b`，未推送。本轮生产流程沿用该生产二进制，
没有修改解析器、桌面会话协议或前端业务行为。

环境为 Linux Mint 22.3、GTK 3.24.41、WebKitGTK 2.52.6。实际 GTK/WebKit 窗口与
原生打开、保存对话框运行在专属 Xvfb 和 D-Bus 会话，通过 AT-SPI 与 X11 键盘输入
操作。每组测试使用 `GSETTINGS_BACKEND=memory`，并隔离 `XDG_CONFIG_HOME`、
`XDG_DATA_HOME`、`XDG_CACHE_HOME`。没有使用模拟 JS host。

## 样本与独立校验

所有媒体均在本机生成；有效编码媒体与容量结构样本分开记录。没有收到真实录制语料。

| 样本 | 大小 / Tag | 校验结果 |
| --- | --- | --- |
| 40 分钟 H.264/AAC | 41,698,926 byte / 172,504 | FFprobe 与 FFmpeg 全量解码成功；60,000 个视频帧、112,501 个 AAC 帧；独立 FLV framing 检查通过 |
| 30 秒 MP3 FLV | 499,066 byte / 1,150 | 44,100 Hz、双声道；全部 1,150 个 MP3 帧解码成功 |
| 1 GiB 填充结构样本 | 1,073,742,902 byte / 67 | 实写 1 GiB 填充；完整索引，尾 Tag 66 的 AVC 配置自动定位、详情成功 |
| 超 Tag 上限结构样本 | 15,000,033 byte / 1,000,001 | 保留 1,000,000 Tag，诊断 `FLV_TAG_LIMIT_EXCEEDED`；最后保留 Tag 为 999999，额外 Tag 1000000 未进入索引 |

后两项分别检验文件字节数与索引数量边界，不把结构填充样本称为可播放媒体。
CLI 对部分索引的详情命令按合同退出 2；超过硬上限的 `--max-tags` 参数退出 64。
桌面保留会话允许读取已提交的部分索引，与 CLI 的完整扫描前置要求不同。

两种容量样本还分别完成生产二进制原生烟测：1 GiB 样本的尾 Tag 66 通过
`candidate_index` 找到 Tag 0 配置，读取到 EOF 的 32 byte Hex；高 Tag 样本显示
部分索引，仍可完整解析 Tag 999999 的 MP3 帧头，其 35 byte Hex 同时覆盖已提交
尾 Tag 和未索引的最后 15 byte。两份快照的 Schema、尾 Tag 位置和 Hex 原始字节
独立核验通过；关闭后源 FD 消失，源哈希不变，父进程退出码为 0，已观察后代均已消失。
大文件比 1 GiB 多 1,078 byte，未修改快照检查器的 1 GiB 源上限来迁就测试；
此项使用独立 Schema、已知尾部位置与逐字节读取核验，未宣称运行完整源检查器。

长媒体关键帧观测数为 1,200，概览保留 1,024 项、明确省略 176 项；MP3 帧头观测
1,150 项，保留 256 项。独立 CLI 使用与桌面相同预算：关键帧 1024、配置事件 128、
配置字节 16 MiB、分析诊断 256、MP3 帧头事件 256。

## 生产二进制的五轮原生操作

同一父进程 PID 1037711 连续完成 `scan-1` 至 `scan-5`：打开长媒体、等待扫描、
跳转 Tag 147200、读取详情、分析媒体、重新读取详情、读取 Hex、查看默认趋势窗口、
通过 GTK 保存快照、关闭媒体。启动媒体分析按现有设计清除详情选择，因此导出前
再次选择详情。

- 每轮完整扫描 172,504 Tag。Tag 147200 是第 1,025 个声明关键帧，超出概览事件
  保留列表，仍能通过索引直接定位，并自动取得 AVC 配置、完整解析详情。
- 五份快照均通过 Schema 与源文件校验；每份全部 112 项概览指标均与独立 CLI
  一致，包括缺失值的展示语义。Hex 对应所选晚期 Tag；趋势覆盖默认 `[0,256)`，
  不是晚期 Tag 附近的窗口。
- 每轮关闭前观察到源 FD，关闭后按设备号和 inode 查找均为空；源 SHA-256 未变。
- 正常 `WM_DELETE_WINDOW` 退出码为 0；已观察的两个 WebKit 后代也消失。
- 有效 MP3 另完成一轮同类原生流程，其快照的 112 项指标、详情、Hex、趋势与源校验通过。

资源数据包含 280 个采样点，跨度 251.558 秒，最大相邻间隔 1.041 秒。下表为每轮
关闭媒体并等待 3 秒后的观测值；FD 列依次为主进程 / WebKit Web / WebKit Network。

| 轮次 | 进程树 RSS 合计 MiB | PSS 合计 MiB | FD 数 | 源文件 FD |
| --- | ---: | ---: | --- | --- |
| 1 | 487.9 | 216.7 | 43 / 29 / 24 | 0 |
| 2 | 509.2 | 237.7 | 43 / 29 / 24 | 0 |
| 3 | 497.1 | 225.6 | 43 / 29 / 24 | 0 |
| 4 | 498.7 | 197.8 | 43 / 29 / 24 | 0 |
| 5 | 501.6 | 230.1 | 43 / 29 / 24 | 0 |

采样中 RSS 合计峰值 530.7 MiB、PSS 合计峰值 258.6 MiB。RSS 合计重复计入共享页；
PSS 也受其他独立测试进程的共享页分摊影响。五轮没有 FD 累积或内存逐轮持续增长，
但这是带 AT-SPI 的短周期观察，不能推导长期无泄漏、精确峰值或无短命子进程。

## 取消、读取中关闭与源变化恢复

取消与关闭的确定性测试复用 `tools/desktop-native/gate.go.txt`，仅通过 Go overlay
包装专属测试文件的 `ReadAt`，在指定读取处阻塞，使用绑定 run ID、PID 和进程令牌的
收据释放。三项使用各自的非生产二进制，保留构建命令、overlay 与哈希；实际窗口、
控制器、Go 会话与文件句柄均参与流程，仓库生产源码和生产二进制未改变。
这些测试证明受控阻塞下的生命周期，不把它们称为自然慢磁盘或生产构建复现。

| 场景 | 实际结果 |
| --- | --- |
| 扫描阻塞后取消 | 读取返回前保持取消中；释放后快照为 `canceled`，恰好保留 Tag 0–9，`bytesScanned=163`，部分索引详情可读 |
| 概览读取阻塞后取消 | 等待底层读取时仍持有源 FD；释放后显示“任务已取消”，同一文档重新分析全部 32 Tag 成功 |
| 概览读取阻塞时关闭文件 | 保持关闭中、不能打开新文件，源 FD 尚未释放；实际读取返回后才关闭 FD、回到空态 |

三项随后均在同一父进程重新打开 32 Tag 文件成功，并正常关闭窗口，父退出码 0，
已观察的 WebKit 后代消失。通过轮次分别为 `scan-cancel-004`、
`summary-cancel-002`、`summary-close`。

源变化另用未插桩生产二进制验证。仅修改专属 497 byte 生成文件副本：追加字节用于
详情和 Hex 入口，等长改写并更新 mtime 用于概览入口。三个入口均提示
“文件内容已改变，请关闭后重新打开”，清除旧结果并禁用读取；关闭后源 FD 消失，
恢复副本原始字节再打开后，AVC 详情与配置定位恢复。包括 Hex 截图补验共完成四次
变化/恢复，同一父进程最终正常退出。未验证恶意保持 size/mtime 的隐蔽改写。

早期验收脚本存在过早匹配扫描占位文字、误把概览启动后清空详情当作失败、
等待 AT-SPI 未暴露的 span 文本、误选隐藏窗口，以及一次 AT-SPI 注册超时。
相关失败目录全部保留，修正辅助脚本后使用新目录重跑；未将失败轮混入通过次数。
关闭瞬间的陈旧 accessibility 节点及一张不完整 Hex 截图也保留，恢复结论使用
FD 记录、后续成功重开和有效补充截图，不依赖这些不完整采集。
