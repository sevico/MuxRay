# 本地桌面预览范围与交付条件

MuxRay 当前交付为用于实际文件诊断的本地开发预览。首个预览包以 Windows x64
为目标，提供默认生产 EXE、[使用指南](preview-guide.md)及构建和验收记录。
它支持只读分析单个本地 FLV 文件，不提供播放、修复或转码功能。

## 支持范围

| 项目 | 本地预览范围 |
| --- | --- |
| Windows x64 | 默认 Wails/WebView2 桌面程序；运行前须已安装 WebView2 Runtime，程序不自动下载安装 |
| Linux | 已有 GTK/WebKitGTK 专项原生验收和 CI；可按[桌面开发说明](../desktop/README.md#linux-构建)构建，不承诺本 Windows 包在 Linux 运行，也尚无 AppImage、deb 或 rpm 包 |
| macOS | 桌面尚未验收，不列入本次预览支持平台 |
| 输入与生命周期 | 单个本地 FLV 文件；扫描、取消、关闭、请求恢复和保留源文件的按需读取；不接入实时 RTMP/HTTP-FLV、多文件会话或边录边看 |
| 容器与定位 | FLV Header、Tag 索引、结构诊断、筛选、原始 DTS 定位、Tag ID、字段/诊断与 Hex 联动 |
| 详情 | AMF0、AAC 配置、AVC/H.264 配置及有界 NAL/slice/SEI 语法、MP3 帧头/边界/side-info/元数据和依赖物理来源 |
| 分析 | 媒体概览、码率与声明 GOP 曲线、局部 Tag 趋势、H.264 证据检索、MP3 变化/停止与 SEI 检索、长文件时间戳检索 |
| 导出 | 原生保存诊断快照 JSON v3/v4，保存已有有界证据；不自动补跑全文件分析 |

主要边界：

- 索引上限为 **1,000,000 个 Tag**。取消、结构错误或预算停止可能留下部分索引；
  到达“当前索引末尾”不一定覆盖完整文件，须同时检查扫描完整性。
- 时间戳检索每批最多检查 4096 个 Tag、显示 64 条结果，需显式继续；仅保留当前批。
  同类型及 Stream ID 的前驱最多保留 512 项，淘汰后未知不补猜。普通趋势每窗
  256 个 Tag，独立回查最多 4096 个前序 Tag；稀疏轨道可能在检索中有前驱、在趋势中未知。
- DTS 是源文件的原始 32 位值，不自动展开回绕。回退、重复、大间隔是观察项；
  不能单独判定媒体损坏、播放卡顿或音画失步。
- “完整”须结合对象和覆盖范围理解：容器索引完整、某段语法完整或帧边界完整，
  都不保证可播放。FLV 关键帧声明、观察到的 IDR NAL、I slice 分别呈现。
- AAC raw、H.264 图像和 MP3 主数据不解码；不重建 MP3 bit-reservoir 或 HRD/DPB
  播放时间线。缺少上下文、格式不支持和资源预算耗尽保留未知或部分结果。
- 详情、Hex、概览和检索都有独立读取及展示预算；未知值和省略范围保留在结果中。
  精确合同见[项目说明](../README.md)和[桌面开发说明](../desktop/README.md)。

## 快照能证明什么

桌面通常导出 v3；有当前已完成的 MP3/SEI 检索页时使用 v4。快照冻结当前已加载的
详情、Hex、概览及事件页、趋势窗口、媒体曲线页和适用的检索页；不会收集历史所有页。
未请求、未完成或已淘汰的部分在 `omitted` 中说明。

**时间戳检索页、累计检索范围和续查游标不在导出中。** 先从命中项进入趋势和详情，
再读取所需 Hex 并导出；检索条件和累计范围另行记录。快照最多 2 MiB，Hex 最多为
已有窗口的 4 KiB 字节。文件中可能包含 AMF 文本和原始媒体字节，分享前应查看内容。

## 已知问题

- 历史默认 Windows 运行的 `exit 1` 尚未归因；后续单次正常退出不等于问题已修复。
- Windows Shell 文件选择路径的 GDI 保留及引用问题仍保留，具体修复结论未完成；
  本地预览不宣称长期资源稳定性已全项通过。
- `pickerprocess` 文件选择辅助进程仍为可选原型，严格六轮复验完成 **0/6**，
  不进入默认预览构建。失败与未复现记录见[Windows 稳定性记录](desktop-windows-stability-20261017.md)。
- 源文件保持打开期间不应被修改。应用检查文件身份、大小和修改时间，但这不是
  不可变快照，不能识别所有同大小、同时间戳的原位修改。

## 本地预览交付门槛

每份交付包应提供可核验记录，而非仅写“测试通过”。实际提交号、摘要、CI 链接和
原生结果由包内构建身份与验收记录承载；以下是判定条件，不是某次构建的通过声明。

| 条件 | 核验方式 |
| --- | --- |
| 源码与产物对应 | 记录完整 Git commit、构建命令和锁定依赖；生产源码无未提交改动；记录最终 EXE 的 SHA-256 |
| 默认构建可复现 | 使用项目默认生产构建入口，不带诊断 overlay 或 `pickerprocess`；生成绑定与提交一致；缺少 WebView2 的处理方式明确 |
| 对应提交的自动检查完成 | 保存相同 commit 的远端 CI 链接、各必需 job 结果；不能用上一提交的绿灯替代。Windows CI 不冒充原生 GUI 验收 |
| 用户任务及改动已核验 | 复用下述既有功能证据，标明其原始构建；对最终构建中新增交互做定向检查，记录界面结果、实际保存、源关闭及正常退出，不宣称旧 EXE 的结果覆盖全部新改动 |
| 导出与证据一致 | 记录所选 Tag/窗口和快照范围；对实际保存的 JSON 做 schema 与源字节核对；没有加载的部分如实省略 |
| 交付内容清楚 | 包含本范围、使用指南、构建身份及验收结果；不附用户源媒体、用户配置或含媒体内容的诊断导出；已知问题随包保留 |

已有可复用证据包括[默认桌面任务试用](desktop-default-trial-20261018.md)、
[时间戳检索完整流程](desktop-time-search-20261018.md)和
[MP3/SEI Windows 验收](desktop-windows-stability-20261016.md)。这些记录各自绑定
所述构建与场景，不累计成“所有平台、所有文件均正常”的结论。

验收以具体任务完成为停止条件，不为预览交付重复整套历史验收或无限追加长期采样。
发生崩溃、无法保存或无法关闭源文件时，保留现场并停止该轮；明确原因后只补受影响
场景的验证。CI、原生任务和长期资源观察分别报告。

## 公开发行前仍需决定或完成

本地预览交付不代表公开发行准备完成。项目已由维护者选择 [MIT 许可证](../LICENSE)。
公开发行仍须包含对应 Go/npm/原生组件的许可通知、完成依赖安全检查，并明确
运行时依赖与使用方式。首个 Windows 发行目标为 x64 portable ZIP，需预装 WebView2；
不包含安装器，也不宣称代码签名或安装/卸载流程已经验收。不分发用户源媒体。

还需根据目标用户确定正式支持平台及版本，明确已知 Windows 退出/资源问题的
处理或接受条件，并为所宣称的发行范围取得对应证据。实时输入、解码预览、修复、
转码和多文件分析属于后续独立功能，不作为本次本地预览的完成门槛。
