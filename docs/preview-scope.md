# 桌面支持范围与使用说明

MuxRay 是用于检查本地 FLV 文件的桌面分析工具，支持从媒体概览、Tag 和字段定位到
原始字节。[v0.1.0](https://github.com/sevico/MuxRay/releases/tag/v0.1.0) 提供
Windows x64 便携版，解压后即可运行，使用步骤见[桌面使用指南](preview-guide.md)。
程序只读分析单个文件，不提供播放、修复或转码功能。

## 支持范围

| 项目 | 支持情况 |
| --- | --- |
| Windows x64 | 默认 Wails/WebView2 桌面程序；运行前须已安装 WebView2 Runtime，程序不自动下载安装 |
| Linux | 可按[桌面开发说明](../desktop/README.md#linux-构建)从源码构建；本次发行不提供 Linux 安装包 |
| macOS | 本次发行不提供 macOS 桌面版 |
| 输入与生命周期 | 单个本地 FLV 文件；扫描、取消、关闭、请求恢复和保留源文件的按需读取；不接入实时 RTMP/HTTP-FLV、多文件会话或边录边看 |
| 容器与定位 | FLV Header、Tag 索引、结构诊断、筛选、原始 DTS 定位、Tag ID、字段/诊断与 Hex 联动 |
| 详情 | AMF0、AAC 配置、AVC/H.264 配置及有界 NAL/slice/SEI 语法、MP3 帧头/边界/side-info/元数据和依赖物理来源 |
| 分析 | 媒体概览、码率与声明 GOP 曲线、局部 Tag 趋势、H.264 证据检索、MP3 变化/停止与 SEI 检索、长文件时间戳检索 |
| 导出 | 通过系统保存对话框导出诊断快照 JSON v3/v4，保存当前已加载的分析结果 |

Windows ZIP 包含桌面程序、使用说明、构建信息、MIT 许可证及第三方许可通知，
不包含 CLI、安装器或 WebView2 Runtime。发行页提供 ZIP 的 SHA-256 校验文件。

## 分析范围

分析按需读取，并为索引、详情和检索设置上限。使用结果时请结合界面显示的扫描状态
和覆盖范围：

- 索引上限为 **1,000,000 个 Tag**。取消、结构错误或预算停止可能留下部分索引；
  到达“当前索引末尾”不一定覆盖完整文件，须同时检查扫描完整性。
- 时间戳检索每批最多检查 4096 个 Tag、显示 64 条结果，需显式继续；仅保留当前批。
  同类型及 Stream ID 的前驱最多保留 512 项，超出保留范围时显示未知。普通趋势每窗
  256 个 Tag，独立回查最多 4096 个前序 Tag；稀疏轨道可能在检索中有前驱、在趋势中未知。
- DTS 是源文件的原始 32 位值，不自动展开回绕。回退、重复、大间隔是观察项；
  不能单独判定媒体损坏、播放卡顿或音画失步。
- “完整”对应当前对象和覆盖范围：容器索引完整、某段语法完整或帧边界完整，
  都不保证可播放。FLV 关键帧声明、观察到的 IDR NAL、I slice 分别呈现。
- AAC raw、H.264 图像和 MP3 主数据不解码；不重建 MP3 bit-reservoir 或 HRD/DPB
  播放时间线。缺少上下文、格式不支持和资源预算耗尽保留未知或部分结果。
- 详情、Hex、概览和检索都有独立读取及展示预算；未知值和省略范围保留在结果中。
  源文件保持打开期间请避免修改；修改后关闭并重新打开，以便刷新索引与分析结果。

## 快照能证明什么

桌面通常导出 v3；有当前已完成的 MP3/SEI 检索页时使用 v4。快照冻结当前已加载的
详情、Hex、概览及事件页、趋势窗口、媒体曲线页和适用的检索页；不会收集历史所有页。
未请求、未完成或已淘汰的部分在 `omitted` 中说明。

**时间戳检索页、累计检索范围和续查游标不在导出中。** 先从命中项进入趋势和详情，
再读取所需 Hex 并导出；检索条件和累计范围另行记录。快照最多 2 MiB，Hex 最多为
已有窗口的 4 KiB 字节。文件中可能包含 AMF 文本和原始媒体字节，分享前应查看内容。

## 已知问题

- Windows 下曾出现异常退出，目前仍在跟进。
- 长时间重复打开系统文件选择框可能增加进程资源占用；如影响使用，可关闭并重新启动程序。

反馈方式见[使用指南](preview-guide.md#遇到问题时记录什么)。
