# 桌面调用等待上限与可复现原生验收（2026-09-10）

本批接续 `ec2d101`，完成其余 IPC 等待恢复和受控原生验收工具化。
不改变桌面 DTO、Go 适配层、CLI 合同、依赖版本或已接受的 ADR。

## 调用恢复

打开、打开确认、取消、关闭、状态、Tag 页和诊断页均采用 5 秒本地等待
上限。打开、命令、状态与分页分别管理等待定时器，某一调用返回不会误清
其他调用的计时。200 ms 状态轮询仍串行；超时只结束前端等待，不撤销
宿主中可能已经执行的操作，也不声称能中断阻塞 I/O。

取消或关闭报错/超时后保留操作占用，先查询实际会话状态，再解锁界面。
不自动重发命令；确认查询失败/超时后停止自动查询，保留手动重试入口。
重试先刷新状态，包括此前已经扫描结束的会话，然后恢复当前结果页。
普通状态或分页查询挂起也能在超时后重试，不再永久停在加载状态。

命令使旧状态查询失效，关闭还释放旧分页等待。旧查询、旧命令、旧会话
或旧页选择的迟到响应不能覆盖当前显示。快速切页合并到最新选择；控制器
销毁时释放所有本地等待与定时器，源文件生命周期仍由宿主管理。

## 可复现工具

工具和操作说明已进入 `tools/desktop-native/`。每次使用仓库外的新目录，
分别生成样本、Go overlay、独立 EXE 和构建/生命周期收据。生产源码不
加入门控；普通 Wails 构建不使用 overlay。每次按锁文件离线安装并重建
前端，要求开发机提前准备 Go/npm 缓存，不依赖私有语料或旧 `dist`。

收据绑定 run、PID 和进程实例；JSON 完整写入后才原子发布，历史记录
不得覆写。非 GUI 工具校验真实源文件取消及部分索引，原生工具记录
操作意图、源关闭与进程退出。界面状态与 Tag 数仍须实际观察并留图，
不能把手工提供的观察值或 MarkCancel/MarkExit 意图标记当作自动 UI 证明。

脚本兼容 Windows PowerShell 5.1 和本机 PowerShell 7.6.5。验证时修复了
5.1 原生 stderr 提前抛错导致丢日志的问题，也在真实窗口试跑中发现了
7.x 自动把 JSON 时间转为 UTC DateTime 后，再次解析会丢时区与亚秒的
问题。首轮 `cancel-001` 的进程身份校验因此误报，没有计作验收通过；
该运行保留，并通过真实窗口关闭。之后使用修复后的工具和新运行目录。

时间转换回归在 5.1 与 7 两个实际 PowerShell 版本通过，覆盖真实 JSON、
带时区字符串、UTC/Local DateTime、DateTimeOffset 和 100 ns 顺序。
故意引入 Go 编译错误的外部工具副本也验证了失败日志保留与非零退出。

## 新 checkout 与最终原生结果

从本地提交 `5cb17af` 建立全新 Git clone，目录名 `MuxRay native verified`
和独立运行目录 `native acceptance` 都包含空格。起始没有 `node_modules`、
`dist` 或 `testdata/private`；按工具 README 完成 `verify-002`、
`cancel-002` 和 `exit-002` 三个新 run。非 GUI race、两次离线前端重建
与 Go overlay 编译通过；构建和原生操作后该 checkout 的 `git status`
仍干净。已验证使用旧目录会被拒绝，原构建记录的哈希保持不变。

| 场景 | 实际结果 |
| --- | --- |
| 非 GUI `verify-002` | 493-byte 样本完整扫描为 32 Tags；受控会话经历 running → canceling → canceled，保留 ID 0–9，源关闭及会话关闭后拒绝分页、独占文件打开均通过。 |
| 原生取消 `cancel-002` | 真实选择器打开本次样本，gate 确认第 23 次读取在 offset 163 阻塞。点击真实取消按钮后先显示“正在取消”；Release 后显示“已取消”、163 B、10 Tags、0 诊断、部分索引，页内 ID 0–9。无源关闭错误，`check.ps1 -Scenario Cancel` 通过，关闭文件恢复空态，随后正常退出。 |
| 阻塞退出 `exit-002` | 读取保持阻塞，watcher 先持有进程句柄；通过真实窗口 Alt+F4 退出。意图标记到 OS 退出为 3310.600 ms，检查上界保持默认 6000 ms；紧接实际按键分发前记录的 UTC 到退出为 3226.5791 ms（含输入分发开销）。退出码 0，无 release/released/closed 收据，文件可独占打开，`check.ps1 -Scenario Exit` 通过。 |

阻塞退出没有 orderly source Close，证明的是宿主等待预算结束后进程退出、
OS 回收句柄；不等于强制中断了底层读取。受控构建用于稳定复现真实 UI、
IPC 和会话生命周期，不能替代未经修改的生产 EXE 在自然慢盘上的验收。

最终两个受控 EXE 均为 15,263,744 bytes。其 gate 路径及 run ID 不同，
因此二进制哈希不同；各自哈希和全部源码/前端/overlay 身份记录在对应
`build-record.json` 中。本次所有生产和受控 MuxRay 进程均已退出。
